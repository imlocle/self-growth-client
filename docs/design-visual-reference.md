# Design Visual Reference

Quick reference for the elegant, calming design system.

## Color Palette

### Primary Colors

- **Sage Green** `#7fb069` - Growth, balance, nature
- **Serene Blue** `#6b9bd1` - Calm, trust, focus
- **Soft Purple** `#a78bca` - Mindfulness, wisdom

### Backgrounds

- **Deep Navy** `#0a0e1a` - Main background
- **Surface** `#1a1f35` - Cards and containers
- **Elevated** `#232a42` - Raised elements

### Text

- **Primary** `#f8fafc` - Main text (high contrast)
- **Secondary** `#cbd5e1` - Supporting text
- **Muted** `#94a3b8` - Less important text

### Semantic

- **Success** `#7fb069` - Positive actions
- **Warning** `#e8b86d` - Caution
- **Danger** `#d97777` - Destructive actions

## Component Quick Reference

### Buttons

- Primary: Sage green, main actions
- Secondary: Serene blue, supporting actions
- Outline: Transparent with border
- Ghost: Minimal, transparent
- Danger: Muted red, destructive

### Cards

- Default: Standard surface
- Elevated: With shadow
- Outlined: Transparent with border

### Badges

- Small/Medium sizes
- 6 variants: default, primary, secondary, success, warning, danger

### Icons

- Small: 36x36px
- Medium: 44x44px (meets accessibility)
- Large: 52x52px
